# انتشار رایگان و اشتراک بین ۸ واحد — بدون هزینه

هدف: اپ روی گوشی همهٔ ساکنین نصب شود و از طریق اینترنت با هم هماهنگ باشد، با **هزینهٔ صفر**.

## فاز ۱ — همین حالا: PWA روی GitHub Pages (۱۰۰٪ رایگان)

اپ به **PWA** تبدیل شد: manifest + سرویس‌ورکر + آیکون. یعنی با باز کردن لینک در گوشی،
گزینهٔ «افزودن به صفحهٔ اصلی / نصب برنامه» ظاهر می‌شود و اپ مثل یک اپلیکیشن بومی باز می‌شود (بدون نوار مرورگر، با کار آفلاین).

فعال‌سازی یک‌بار توسط صاحب مخزن:
1. GitHub → Settings → Pages → Source: **GitHub Actions**
2. اکشن `انتشار اپ مدیر ساختمان` خودکار اجرا می‌شود
3. آدرس نهایی: `https://<username>.github.io/social-media-skills/`

هزینه: صفر. نگهداری: صفر. لینک را در گروه بله می‌فرستید و هر ۸ نفر نصب می‌کنند.

محدودیت این فاز: داده‌ها روی گوشی هر نفر جداست (هنوز مشترک نیست).

## فاز ۲ — دادهٔ مشترک بین همه، باز هم رایگان

گزینه‌های سرویس ابری با پلن رایگان دائمی (نه آزمایشی):

| گزینه | سقف رایگان | مناسب برای |
|---|---|---|
| **Supabase** | ۵۰۰MB دیتابیس + Realtime | بهترین گزینه: دیتابیس + همگام‌سازی زنده |
| **Firebase (Spark)** | ۱GB + ۵۰k خواندن روزانه | ساده‌تر، بدون SQL |
| **Cloudflare Workers + D1** | ۱۰۰k درخواست روزانه | سبک‌ترین |

برای ۸ واحد، مصرف ماهانه در حد چند مگابایت است؛ هیچ‌وقت از پلن رایگان خارج نمی‌شوید.
ورود هم رایگان و بدون رمز: یک «کد ساختمان» مشترک + انتخاب واحد، یا لینک دعوت یک‌بارمصرف.

## فاز ۳ — ربات بله (رایگان)

ساخت ربات در بله رایگان است؛ فقط جایی برای اجرای وبهوک لازم است:
- **Cloudflare Workers** (رایگان) یا **Deno Deploy** (رایگان) برای پاسخ‌دهی ربات
- **GitHub Actions با زمان‌بند cron** (رایگان) برای کارهای دوره‌ای: صدور شارژ اول ماه، یادآوری هر ۱۲ ساعت، بستن رأی‌گیری‌ها

نکتهٔ مهم: دسترسی سرویس‌های خارجی به API بله باید عملاً تست شود؛ اگر مسدود بود،
همان PWA + دیتابیس رایگان کار را انجام می‌دهد و اعلان‌ها به‌صورت Web Push (رایگان) ارسال می‌شوند.
