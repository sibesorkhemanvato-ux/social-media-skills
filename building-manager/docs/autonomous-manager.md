# مدل «مدیر خودکار» — ساختمان بدون مدیر انسانی

سند طراحی برای ساختمان ۸ واحدی. اصل بنیادی: **هیچ‌کس ادمین نیست**؛ اپ مجری بی‌طرفِ قانون‌نامه‌ای است که ساکنین یک‌بار تصویب می‌کنند.

## قانون‌نامهٔ مصوب (نسخه ۱)

| بند | مقدار |
|---|---|
| نصاب تصویب | ۵ رأی از ۸ واحد |
| سقف هزینه بدون رأی | ۳۰۰٬۰۰۰ تومان (با فاکتور) |
| سقف هزینه اضطراری بدون رأی | ۱٬۵۰۰٬۰۰۰ تومان + اعلان فوری |
| مهلت پرداخت شارژ | ۱۰ روز پس از صدور |
| جریمه دیرکرد | درصدی (۰٫۱٪ روزانه روی مانده) از روز ۱۰ پس از مهلت |
| هشدار خودکار | هر ۱۲ ساعت پس از مهلت |
| عمومی‌شدن بدهی | پس از ۳ روز تأخیر و ۶ هشدار |
| مهلت رأی‌گیری | ۴۸ ساعت، هر واحد یک رأی |

همهٔ این اعداد فقط از راه **پیشنهاد → رأی‌گیری → تصویب ۵ از ۸** تغییر می‌کنند؛ حتی سازندهٔ اپ هم نمی‌تواند دستی عوضشان کند.

## موتور خودکار

1. اول هر ماه: صدور شارژ ۸ واحد و اعلان به همه
2. پایان مهلت: یادآوری خودکار هر ۱۲ ساعت
3. روز ۳ تأخیر + ۶ هشدار: بدهی در داشبورد عمومی همه نمایش داده می‌شود
4. روز ۱۰ پس از مهلت: شروع جریمهٔ درصدی روزانه
5. هزینه ≤ ۳۰۰ هزار: ثبت خودکار؛ > آن: رأی‌گیری ۴۸ ساعته و اجرای خودکار نتیجه
6. نوبت‌های اجرایی (نظافت، خرید، هماهنگی سرویس‌کار) چرخشی بین واحدها
7. هر رویداد در دفتر رویدادهای غیرقابل حذف ثبت می‌شود

## فاز بعدی: نسخهٔ سرور + ربات بله

- بک‌اند Node + دیتابیس مشترک برای هر ۸ واحد
- ورود با شماره موبایل از طریق ربات بله (بدون رمز)، بدون نقش ادمین
- ربات: `/شارژ` `/بدهی` `/پرداخت` (عکس فیش) `/تعمیرات` `/رأی` `/گزارش`
- زمان‌بند سمت سرور برای صدور شارژ، یادآوری، جریمه و بستن رأی‌گیری‌ها
- توکن ربات فقط در `.env` سرور؛ هرگز در مخزن یا مرورگر
