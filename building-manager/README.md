# 🏢 مدیر ساختمان

یک وب‌اپلیکیشن فارسی (RTL) برای مدیریت آپارتمان و مجتمع مسکونی: واحدها و ساکنین، محاسبه و وصول شارژ ماهانه، دفتر هزینه‌ها و صندوق، تابلوی اعلانات، درخواست‌های تعمیرات و گزارش‌های مالی.

## امکانات

| بخش | توضیح |
|---|---|
| داشبورد | موجودی صندوق، درصد وصول شارژ ماه، بدهکاران، نمودار ۶ ماهه، آخرین اعلانات و درخواست‌ها |
| واحدها و ساکنین | افزودن/ویرایش/حذف واحد، مالک و ساکن، متراژ، نفرات، پارکینگ، واحد خالی، شارژ و بدهی هر واحد |
| شارژ و پرداخت‌ها | صدور خودکار شارژ برای هر ماه شمسی، ثبت پرداخت، وضعیت پرداخت‌شده/ناقص/پرداخت‌نشده |
| هزینه‌ها و صندوق | ثبت هزینه‌ها به تفکیک دسته، نمودار دسته‌بندی، محاسبه موجودی صندوق |
| تابلوی اعلانات | انتشار اعلان با دسته‌بندی و قابلیت سنجاق کردن |
| درخواست تعمیرات | برد سه‌ستونی (باز / در حال بررسی / انجام‌شده) با اولویت و مسئول پیگیری |
| گزارش‌ها | عملکرد ماهانه، صورت‌حساب بدهکار/بستانکار هر واحد، خروجی CSV |
| نگهداری آسانسور | ثبت سوابق سرویس، هزینه‌ها و یادآوری خودکار دوره‌ای |
| درباره و راهنما | راهنمای شروع سریع و اطلاعات طراح نرم‌افزار |
| تنظیمات | مشخصات ساختمان، فرمول شارژ، پشتیبان‌گیری/بازیابی JSON، بازنشانی |

## فرمول شارژ

هزینه‌های مشترک ماهانه به‌صورت برابر میان تمام واحدها تقسیم می‌شوند:

```
شارژ هر واحد = (نظافت + آب + آسانسور + برق مشاعات + متفرقه) ÷ تعداد واحدها
```
واحدهای خالی نیز سهمی برابر با سایر واحدها دارند.

## اجرا

```bash
cd building-manager
npm install
npm run dev      # http://localhost:5173
npm run build    # خروجی در dist/
```

## نکات فنی

- React 19 + Vite، بدون بک‌اند.
- تمام داده‌ها در `localStorage` مرورگر ذخیره می‌شوند (کلیدهای `bm.*`) و با داده‌های نمونه شروع می‌شود.
- تاریخ‌ها با تقویم هجری شمسی (`Intl` با تقویم persian) نمایش داده می‌شوند.
- فونت وزیرمتن از CDN بارگذاری می‌شود؛ در حالت آفلاین فونت سیستمی جایگزین می‌شود.
